## PRD: Update About Page Only (Match Landing Page Theme) — kingofkingsgroup.com

### 1) Overview

**Objective:** Update the **About page** of **kingofkingsgroup.com** with new copy and a polished layout that **matches the existing landing page theme** (same typography scale, spacing rhythm, section width, button styling, and visual patterns).

**Hard constraint:** **Only modify the About page**. Do not change any other pages, routes, components, global styles, config, or backend logic.

---

### 2) Goals

* Publish a premium, credible About page for:

  1. **King of Kings Group (company overview)**
  2. **Ragy Moussa (partner/founder bio)**
* Ensure the About page looks like it was designed as part of the **current landing page theme**.

---

### 3) Non-Goals (Out of Scope)

* Editing Home/Landing page, Services, Contact, Footer, Nav, Blog, or any other route
* Creating new routes or redesigning branding
* Changing global CSS/theme tokens, Tailwind config, layout wrappers, shared component styles
* Adding new dependencies/packages
* Building a CMS or adding backend functionality

---

### 4) Success Criteria

* The About page contains the exact sections and copy in this PRD.
* The About page visually matches the landing page:

  * same **max-width/container**
  * same **vertical section padding**
  * same **heading/subheading styles**
  * same **button component/class styling**
  * same **card/background patterns** if used on landing
* No regressions elsewhere:

  * no visible changes to any other pages
  * no new console errors
  * no broken links
* Mobile responsive:

  * no horizontal scroll
  * readable line lengths and spacing

---

### 5) Scope (In-Scope)

* Update About page content and layout **within the About page file only**
* Use existing theme primitives/patterns:

  * existing `Container`, `Section`, `Button`, `Card`, etc. if already used on landing page
  * existing utility classes used by landing page sections
* Optional About-only styling **only if already supported** (e.g., existing About CSS module already imported by About page)

---

### 6) Theme-Matching Requirements (Critical)

**The About page must follow the landing page theme without modifying global files.**

#### 6.1 Layout primitives

* Reuse the same container/section patterns used on the landing page:

  * same max width (e.g., `max-w-*`, `container`, `mx-auto`)
  * same padding approach (e.g., `px-*`, `py-*`)
* If the landing page uses a `Section` or `Container` component/class pattern, apply the same pattern in About.

#### 6.2 Typography

* Hero title must match landing hero heading style (size/weight/tracking).
* Hero subheading must match landing subtitle style.
* Section headings (H2/H3) must match landing section heading styles.
* Paragraph text must match landing base text size/leading/color.

#### 6.3 Spacing rhythm

* Match landing page section spacing:

  * use the same vertical padding values used between sections on landing (example patterns: `py-16`, `py-20`, `space-y-6`, etc.)
* Keep consistent gaps between heading → body → bullets across sections.

#### 6.4 Buttons and CTAs

* Use the exact same **button component or classes** as landing page primary CTA.
* CTA must link to an **existing route** (likely `/contact`). Do not create a new route.

#### 6.5 Cards / Background patterns

* If landing page uses cards (rounded corners, borders, shadows), reuse that same card style for:

  * “Our Approach” block
  * “Meet Ragy Moussa” block
* If landing page alternates background colors (light gray sections, gradients), About page should follow the same pattern **using existing classes only**.

#### 6.6 Global theme safety

* Do **not** edit:

  * global CSS
  * theme providers
  * Tailwind config
  * shared components’ internals
  * layout wrapper
  * header/footer

---
